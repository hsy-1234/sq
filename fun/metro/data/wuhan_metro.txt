# 生成规则：
#   1. 站序、站名、经纬度取自高德线路详情页；站名相同的站自动合并为换乘站。
#      （高德地铁总图 JSON 漏了 7 号线“余彭塆”，本文件已补齐。）
#   2. 站间距 = 相邻站球面直线距离 × 线路校准系数；
#      校准系数 = 高德线路页“全程 X 公里” / 该线直线距离之和，
#      因此每条线路的 STOP 里程合计与该线官方里程一致。
#   3. 运行时间按平均旅速 34 km/h 估算，四舍五入到分钟，最小 1 分钟。
#   4. 12 号线为环线（SEG 的 loop=1）：末站“省农科院南”的 km/min
#      表示回到首站“楚祥大道”的闭环边，不是 0 0。
